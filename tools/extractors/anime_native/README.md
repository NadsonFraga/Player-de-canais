# Native Anime Stream Extractor Specification

- **Website / Host**: `zokoanime.video` / native anime CDN
- **Role**: Native anime player (Player Nativo Animes) in Tvzinha Online.
- **Media Types**: Animes (subtitled / dubbed).
- **Delivery**: HLS via Cloudflare Signed Stream Proxy (`/api/stream`).

## Architecture & Integration Details

1. **Title Matching & ID Resolution**:
   - Matches TMDB title + original Japanese title with MyAnimeList (MAL) catalog.
   - Fallback to Jikan API when direct MAL lookup is throttled.
   - Shared concurrent lookup cache prevents redundant requests and 405 WAF blocks.
2. **Episode Numbering Rule (A6)**:
   - Evaluates multi-season anime entries:
     - Single-entry long series (Dragon Ball Z, One Piece, Naruto) map season/episode to absolute series numbers.
     - Split-season series (Jujutsu Kaisen S2, Attack on Titan) map to relative episode numbers within each MAL entry.
     - Probes episode `⌈0.9 * total⌉` on the host to verify entry boundaries reliably.
3. **AniSkip Integration**:
   - Queries AniSkip API with MAL ID + episode number to fetch timestamp ranges for Intro (OP), Outro (ED), and Recap.
   - Renders skip buttons and triggers next-episode card at the start of the outro.
4. **Proxy Requirements**:
   - Video segments return `403 Forbidden` without the upstream anime host `Referer`.
   - Streaming is routed through `/api/stream` with signed HMAC tokens generated by `/api/resolve`.
