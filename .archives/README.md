# Tvzinha — Archives & Documentation

Project documentation folder (replaces the former `docs/`).

- `plans/` — task plans (`<task>.md`)
- `summaries/` — completion summaries (`<task>-summary.md`) and handovers; start with the newest one
- `scopes/` — long-lived specs: architecture, design system, sources, streaming engine
- `history/` — chat history exports (made with `old/tools/export_chat_history.py`)
- `reference/` — reference dumps
- `old/` — legacy assets
- `old/tools/` — retired diagnostic scripts from the single-file era (browser inspectors, scroll and overflow tracers, chat export); kept for reference, not used by the site or the workflow
